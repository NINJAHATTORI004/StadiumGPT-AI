# Testing

## Test Types

- Backend unit tests cover AI routing, auth validation, and operation services.
- Frontend component tests cover dashboards, forms, and accessibility semantics.
- Playwright E2E checks landing, login, AI chat, dashboard navigation, and axe accessibility.
- CI runs linting, type checking, tests, and production builds.

## Commands

```bash
npm run lint
npm run typecheck
npm run test
npm run build
npm run test:e2e
```
